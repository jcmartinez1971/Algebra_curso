NIVEL 1 · CONCEPTO

¿Qué es una ecuación cuadrática?

Una ecuación cuadrática, también llamada ecuación de segundo grado, es una ecuación en la que el exponente mayor de la variable es 2.

\(ax^2+bx+c=0\)
Recuerda: el valor de a no puede ser 0. La variable normalmente es x.

¿Qué representan a, b y c?

ElementoFunción
aCoeficiente de x²
bCoeficiente de x
cTérmino independiente
Ejemplo:
\(2x^2+5x+3=0\)

a = 2    b = 5    c = 3

NIVEL 2 · IDENTIFICACIÓN

Reconoce una ecuación cuadrática

Algunas ecuaciones no aparecen inmediatamente en la forma \(ax^2+bx+c=0\). Podemos reorganizarlas.

Ejemplo:

\(x^2=3x-1\)

Movemos todos los términos al lado izquierdo:

\(x^2-3x+1=0\)

Por tanto: a = 1, b = −3, c = 1

Otro ejemplo:

\(2(w^2-2w)=5\)

Desarrollamos:

\(2w^2-4w-5=0\)

Por tanto: a = 2, b = −4, c = −5

NIVEL 3 · SOLUCIONES

¿Qué significa resolver una ecuación?

Las soluciones son los valores de la variable que hacen que la ecuación sea igual a cero. También pueden llamarse raíces o ceros.

Una ecuación cuadrática puede tener dos soluciones reales, una solución real o soluciones complejas, dependiendo del discriminante.

El discriminante

Δ = \(b^2-4ac\)
Valor de ΔTipo de soluciones
\(\Delta>0\)Dos soluciones reales
\(\Delta=0\)Una solución real
\(\Delta<0\)Dos soluciones complejas

NIVEL 4 · LA FÓRMULA

La fórmula cuadrática

x = (−b ± √(\(b^2-4ac\))) / 2a

El símbolo ± significa que debemos considerar dos posibilidades: una con suma y otra con resta.

  1. Identifica los valores de a, b y c.
  2. Calcula el discriminante \(b^2-4ac\).
  3. Sustituye los valores en la fórmula.
  4. Realiza las operaciones.
  5. Obtén las soluciones.
Ejemplo paso a paso:

Resolver:

\(5x^2+6x+1=0\)

1. Identificamos:

a = 5, b = 6, c = 1

2. Sustituimos:

\[\displaystyle x=\frac{-6\pm\sqrt{6^2-4(5)(1)}}{10}\]

3. Calculamos:

\[\displaystyle x=\frac{-6\pm\sqrt{16}}{10}\]

4. Como √16 = 4:

\[\displaystyle x=\frac{-6\pm4}{10}\]

5. Resultado:

\[\displaystyle x=-0.2\quad\text{o}\quad x=-1\]
